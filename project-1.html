Project Overview

The Mang Inasar Ordering System is a front‑end mockup application built with VB.NET Windows Forms, designed to simulate a complete food ordering experience. Although it does not connect to a live database or backend, the interface is fully dynamic and interactive – users can browse a sample menu, add items to a cart, and see quantities and running totals update in real time. The mockup demonstrates how customers would navigate the ordering flow, from menu selection to checkout, with multiple payment options represented (credit card, cash on delivery) as clickable choices.

On the administrative side, the mockup includes placeholder screens for order tracking, menu management, and simple sales reports. These screens are populated with static data to illustrate the layout and functionality that would eventually be connected to a real backend. All interactions are handled locally, making it an ideal prototype for user testing and design validation before full development.

While the current version does not persist data or process actual payments, it successfully captures the look, feel, and workflow of a modern ordering system. The project showcases skills in UI design, event‑driven programming, and creating responsive desktop interfaces – serving as a foundation for future integration with databases and live services.
