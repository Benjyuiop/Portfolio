Project Overview

The Library Management System is a full‑stack web application built with ASP.NET C# and an Oracle Database backend, delivering a complete digital transformation for library operations. The platform is divided into two distinct interfaces: a patron‑facing portal for students and members, and a comprehensive admin dashboard for librarians. On the user side, members can search the catalog by title, author, or keyword, view real‑time availability, place holds, and borrow or return items – all with due‑date tracking and automated email reminders.

The system enforces rules such as borrowing limits and late‑fee calculations, which are updated instantly in the user's account. For librarians, the admin dashboard provides tools to manage the entire collection: adding new titles, updating metadata, handling lost or damaged items, and generating detailed reports on circulation statistics, popular categories, and overdue materials. User authentication is secured through ASP.NET Identity, with role‑based access ensuring that administrative functions are strictly controlled.

The Oracle database backend guarantees data integrity, supports complex queries for reporting, and scales efficiently as the collection grows. By digitizing manual processes and providing self‑service capabilities, the Library Management System enhances user experience, reduces administrative workload, and provides valuable analytics for better collection development.
